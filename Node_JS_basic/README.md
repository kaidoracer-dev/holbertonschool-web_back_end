Node_JS_basic
Description

This project introduces the basics of Node.js. It covers file handling, HTTP servers, Express, and working with asynchronous code.

Requirements
Node.js 20.x.x
Ubuntu 20.04 LTS
ESLint
Jest
Installation

Install dependencies:

npm install

Run

Start a file:

node filename.js

For development:

npm run dev

Tests

Run tests:

npm test

Run full checks:

npm run full-test
