# ES6_classes

## Description
This project covers ES6 classes in JavaScript: how to define them, add methods, static methods, extend classes, and use metaprogramming with symbols.

## Learning Objectives
- How to define a Class
- How to add methods to a class
- Why and how to add a static method to a class
- How to extend a class from another
- Metaprogramming and symbols

## Requirements
- Node.js 20.x.x
- npm 9.x.x
