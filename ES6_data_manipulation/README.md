ES6 Data Manipulation

Description

This project covers ES6 data manipulation in JavaScript, including arrays, typed arrays, and data structures like Set and Map.

Objectives

Use map, filter, and reduce

Understand typed arrays

Work with Set and Map

Requirements

Node.js 20.x

All functions must be exported

Code tested with Jest

Code must pass ESLint

Setup

npm install
Run Tests
npm run test
npm run full-test

Files

Each file implements a specific function for data manipulation tasks.
